# Which three emojis are the Scoring reactions?

Type: grilling
Status: resolved

## Question

Which Telegram emoji is Karma plus, which is Karma minus, and which is Humor? Standard emoji only, or custom emoji? They must be distinct, and Karma plus/minus mutually exclusive for one Member on one message.

## Answer

👍 = Karma plus, 👎 = Karma minus, 🤣 = Humor. Standard emoji only.
