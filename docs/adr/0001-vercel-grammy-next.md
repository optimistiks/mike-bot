# Host v2 on Vercel with Grammy and Next.js

v1 runs on AWS CodeStar / Lambda / Telegraf. v2 is a new BotFather bot on a new `v2` branch, hosted on Vercel: Grammy for the webhook, Next.js for the Mini App.

We are not staying on Lambda, and we are not copying redesigned-giggle's stack (TanStack Start + Kamal/VPS). Giggle is a pattern reference only (webhook, reactions, initData).
