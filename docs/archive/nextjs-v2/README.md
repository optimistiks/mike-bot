# Archived: Next.js Mini App domain

Frozen 2026-09-02.

This directory is the glossary, ADRs, and research notes for the Next.js Mini
App and its extended bot — Scoring reactions, Seasons, Registration, the
Leaderboard UI. That source stays in `apps/web`. It is not the live model.

The live product is a from-scratch Hono Telegram bot. Its glossary is the
repo-root `CONTEXT.md`. Its decisions are `docs/adr/`. Cherry-pick
implementation from `apps/web` and vocabulary from here only when the live
docs record that cherry-pick again.
